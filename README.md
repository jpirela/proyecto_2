Este proyecto se trata de la encriptacion y desencriptacion de texto, apartir de lo que ingrese el usuario.
El proyecto como tal consiste de 2 entradas de texto, una para el texto a encriptar/desencriptar y otra para la llava que se usara.

La carpeta proyecto contiene 2 carpetas, una que contiene la version de escritorio y otra que contiene la version web.


La version de escritorio esta hecha con glade y sqlite.


La version web esta hecha con flask, request y flask-sqlalchemy.


Tambien existe un archivo llamado prototipo, que contiene el proceso con el cual cree y probe el codigo.
