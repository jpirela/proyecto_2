Esta es una aplicación web simple diseñada para gestionar una lista de alumnos. Su funcionalidad principal se centra en dos acciones clave:

1. Añadir nuevos alumnos: Para registrar a un nuevo estudiante, debes completar los campos del formulario con su Nombre, Apellido y Cédula. Una vez que hayas ingresado la información, haz clic en el botón "Agregar Alumno". La aplicación verificará que la cédula sea única antes de añadirlo a la lista.

2. Ver y Eliminar alumnos existentes: Todos los alumnos que agregues se mostrarán automáticamente en una tabla a la derecha. Junto a cada alumno listado, encontrarás un botón "Eliminar". Si deseas remover a un alumno de la lista, simplemente haz clic en el botón "Eliminar" correspondiente a ese alumno y confirma la acción.

Es importante tener en cuenta que esta versión de la aplicación utiliza una base de datos temporal en la memoria. Esto significa que los datos de los alumnos se guardarán solo mientras la aplicación esté activa. Si el servidor de la aplicación se cierra (por ejemplo, si cierras la terminal o detienes el proceso), la lista de alumnos se reiniciará y los datos anteriores se perderán.
